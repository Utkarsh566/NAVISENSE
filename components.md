# Hardware Components

## Core
1. Arduino Nano
2. HC-SR04 or compatible ultrasonic sensor ×2
3. Buzzer
4. NEO-6M GPS module
5. ESP8266 NodeMCU or ESP32
6. Battery/power source
7. Walking-stick frame and mounting hardware

## Optional Future Hardware
- MPU6050 IMU
- DFPlayer Mini
- Speaker/headphones
- OLED display
- Battery voltage sensor
