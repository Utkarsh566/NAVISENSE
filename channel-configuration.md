# ThingSpeak Channel Configuration

Suggested fields:

| Field | Data |
|---|---|
| Field 1 | Obstacle distance (cm) |
| Field 2 | Ground/pothole sensor distance (cm) |
| Field 3 | GPS latitude |
| Field 4 | GPS longitude |
| Field 5 | Alert state |
| Field 6 | Device status |

## Setup
1. Create a ThingSpeak channel.
2. Enable the required fields.
3. Copy the channel ID.
4. Create a write API key.
5. Keep credentials out of Git.
6. Add charts/widgets.
7. Respect the update limits of your ThingSpeak account/channel.
